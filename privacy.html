Doodle Planet Uploader — Privacy Policy

Effective 28 October 2026 · Applies to the “Doodle Planet Uploader” API client

In short: Doodle Planet Uploader is a private tool used by one person — the owner of the YouTube channel Doodle Planet — to upload their own videos to their own channel. It does not collect, store, share or sell anyone else’s data.

What the tool is

Doodle Planet Uploader is a private command-line script that uses the YouTube API Services to upload the channel owner’s finished videos, captions and thumbnails to the Doodle Planet channel, as private videos for review before publishing. It is not offered to, or used by, anyone else.

YouTube API Services

This tool uses the YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Information handled through the YouTube API Services is also subject to the Google Privacy Policy.

Information accessed and stored

  • Google sign-in token: when the channel owner signs in, Google issues an access token, which is stored only on the owner’s own computer so the tool can upload without signing in every time.
  • Uploaded video ID: after an upload, the new video’s ID is saved in a local file so the owner can find the video.
  • The tool does not read, collect or store any other YouTube data, and never accesses other users’ channels, videos, comments or personal information. It uses no cookies, analytics or tracking.

Use and sharing

The information above is used only to upload the owner’s own videos. It is not shared with, sold to, or disclosed to any third party, and it is not used for advertising.

Retention and deletion

The sign-in token stays on the owner’s computer until it expires or is deleted. Access can be revoked at any time from the Google security settings page, which immediately stops the tool from accessing the account.

Contact

Questions about this policy can be sent through the contact details on the Doodle Planet channel’s About page.
